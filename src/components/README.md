# Components

This directory contains React components for the SkeletonMap application.

## Structure

- **XRayViewer** - Component for displaying and interacting with X-ray images
- **ModelViewer** - Component for displaying and interacting with 3D bone models
- **EducationalPanel** - Component for displaying educational content about bones
- **UploadHandler** - Component for handling file uploads
- **Layout components** - Header, SplitLayout, etc.

## Guidelines

- Each component should be in its own file or folder
- Use TypeScript for all components
- Follow React best practices and hooks
- Keep components focused and single-purpose
