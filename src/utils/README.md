# Utils

This directory contains utility functions and helpers for the BoneVision application.

## Utilities

- **geometry.ts** - Point-in-polygon detection, coordinate scaling, etc.
- **animation.ts** - Animation easing functions and helpers
- **constants.ts** - Application constants (if not in types)
- **format.ts** - Data formatting helpers

## Guidelines

- Keep utility functions pure and testable
- Group related utilities in the same file
- Export individual functions, not default exports
- Add JSDoc comments for complex utilities
